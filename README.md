# Harmonic Bench

> プロジェクト名は仮称です。実装仕様は [PLAN.md](./PLAN.md)（仕様書内の旧仮称は「Chord Lab」）を参照してください。

ブラウザ上の鍵盤で単音や和音を鳴らしながら、音名・周波数・音程・和音名を確かめられる、音楽理論の学習・探索用Webアプリです。
バックエンドやアカウント登録は不要で、音はすべてブラウザ内（Web Audio API）で合成します。

## 起動方法

Node.js 22.22 以降または 24.15 以降が必要です（テスト環境の jsdom / Vitest の要件。開発時は v24.18 で確認）。

```bash
npm install
npm run dev       # 開発サーバー（http://localhost:5173）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果をローカルで確認
```

その他のスクリプト:

| コマンド                      | 内容                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| `npm run test`                | ユニットテスト・UIテスト（Vitest + React Testing Library） |
| `npm run test:watch`          | テストの監視実行                                           |
| `npm run typecheck`           | TypeScript の型チェック                                    |
| `npm run lint`                | Biome の lint のみ                                         |
| `npm run format`              | Biome で整形して書き込む                                   |
| `npm run check` / `check:fix` | Biome の lint・整形・import整理をまとめて検査 / 自動修正   |

## 使い方

- **和音作成モード**（初期）: 鍵盤をタップ／クリックするたびに音を選択・解除します。追加時は短いプレビュー音が鳴ります。「和音を再生」で選択音を同時に約1秒鳴らし、「全解除」で選択を空にします。選択は最大12音です。
- **演奏モード**: 鍵盤を押している間だけ音が鳴ります。複数の鍵盤を同時に押せます。分析は押下中の音を対象にします。
- **オクターブ**: 「−」「＋」で表示する2オクターブを C2–B3 〜 C5–B6 の範囲で切り替えます。画面外に移った選択音も保持されます。
- **PCキーボード**（物理キー位置で判定）:
  - 下段 `Z S X D C V G B H N J M` → 表示中の低いオクターブの C〜B
  - 上段 `Q 2 W 3 E R 5 T 6 Y 7 U` → 表示中の高いオクターブの C〜B
  - キーリピート、IME変換中、Ctrl/⌘/Alt 併用時、入力欄（音色・音量など）にフォーカスがあるときは反応しません。

## 構成

```text
src/
├── theory/      音楽理論（React・ブラウザ非依存の純粋なTypeScript）
│   ├── pitch.ts           MIDI↔周波数、ピッチクラス
│   ├── noteSpelling.ts    音名の綴り（♯/♭、根音＋度数からの綴り）
│   ├── intervals.ts       音程名（半音数から／綴りから）
│   ├── chordTemplates.ts  13種類のコードテンプレートと日本語解説
│   ├── detectChord.ts     和音候補の検出・並べ替え・転回形
│   └── analyze.ts         画面表示用の分析結果（単音／音程／和音／判定不能）
├── audio/       Web Audio API による音声エンジン（UIをimportしない）
│   ├── AudioEngine.ts     発音・停止・入力元追跡・音量・後片付け
│   └── timbres.ts         6種類の合成音色とエンベロープ
├── hooks/       useAudioEngine / useKeyboardInput
├── components/  鍵盤・コントロール・分析表示
└── styles/      app.css
tests/           Vitest のテスト
```

設計上のポイント:

- 発音は操作イベントから Audio Engine を直接呼びます。再描画や `useEffect` を発音のきっかけにしていません。
- 和音名・周波数・音程はすべて選択音（または押下音）から計算する派生データです。
- 和音判定はテンプレートとの完全一致のみです。同じ構成音に複数の解釈がある場合（C6 / Am7、増三和音、減七和音など）は候補をすべて表示します。

## CI

`.github/workflows/biome.yml` で、プルリクエストの作成・更新時と `master` への push 時に `biome ci` を実行します。Biome のバージョンは `package.json` に固定したもの（`biomejs/setup-biome` が自動で読み取る）を使います。

## 公開

`npm run build` で生成される `dist/` は静的ファイルのみで構成されており、Cloudflare Pages などの静的ホスティングにそのまま配置できます（ビルドコマンド `npm run build`、出力ディレクトリ `dist`）。
iOS Safari などでは音声再生に HTTPS（または localhost）が必要です。

## 動作上の制約・既知の問題

- 音色はすべて合成音です。「プラック／ピアノ風」も実際のピアノ音ではありません。
- 和音の綴り（C♯/D♭ など）はキーを選べないため暫定的です。黒鍵が根音のときは、構成音の変化記号が少ない綴りを選びます（例: D♭、C♯m）。和音が定まらない音集合は、C♯ / E♭ / F♯ / A♭ / B♭ を基本とした暫定表記です。
- 和音の文脈がない2音の音程は半音数から判定します。そのため6半音は「増4度／減5度」と表示します。
- 演奏モードで鍵盤上を横にスワイプしてスクロールすると、押し始めの音が一瞬鳴ってから止まります（スクロール開始時に `pointercancel` で停止）。
- IMEがオンの状態ではPCキーボード演奏は反応しません（IME操作との衝突を避けるため）。
- 押している最中にオクターブを切り替えると、押下中の音は止まります。
- 発音の遅延はブラウザ・端末の音声処理に依存し、低遅延は保証しません。
- 端末が消音モード（iOS のサイレントスイッチなど）の場合、音が出ないことがあります。
